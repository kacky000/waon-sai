GitHub連携設定

管理画面で編集したデータを GitHub リポジトリの data.json にコミットします。
GitHub Pages や外部サーバーでホスティングしている場合、全員に反映されます。

GitHub > Settings > Developer settings > Personal access tokens > Fine-grained tokensで作成。
必要な権限: Contents (Read and write)。トークンはこのブラウザのlocalStorageにのみ保存されます。
